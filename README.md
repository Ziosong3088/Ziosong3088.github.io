# Zio Song — Portfolio Website (GitHub Pages, 100% free)

This folder IS your website. Upload it to GitHub once and it's live for free at
`https://YOUR-GITHUB-USERNAME.github.io`

## Put it online (5 minutes, no code)

1. Go to https://github.com and sign up / log in (free account).
2. Click **+** (top right) → **New repository**.
3. Name it exactly: `YOUR-GITHUB-USERNAME.github.io`
   (example: if your username is `ziosong`, name it `ziosong.github.io`)
   Set it to **Public**, then **Create repository**.
4. On the repo page, click **uploading an existing file** (or **Add file → Upload files**).
5. Drag in ALL the files from this folder:
   `index.html`, `styles.css`, `.nojekyll`, and the whole `images` folder.
   Then click **Commit changes**.
6. Wait 1–2 minutes, then open `https://YOUR-GITHUB-USERNAME.github.io` — your site is live.

## Update it later

- Change words: edit `index.html` right on GitHub (pencil icon) — or ask Yerin.
- Add a new artwork: upload the image into the `images` folder on GitHub,
  then copy one of the `<article class="card">…</article>` blocks in `index.html`
  and change the title, text, and image name.
- Add ArtStation / Instagram / LinkedIn links: in `index.html`, find the
  commented block at the bottom of the Contact section, fill in your URLs,
  and remove the `<!--` and `-->` around it.

## Files

- `index.html` — all the text and structure
- `styles.css` — black & gold styling
- `images/` — your artwork (drapery chair charcoal study, creature sketch, animatic stills)
- `.nojekyll` — tells GitHub Pages to serve the files exactly as-is
